# 곰돌찡 ♥ 토끼찡

## 폴더 구조
```
couple/
├─ index.html          페이지
├─ app.js              잠금 · 갤러리 · 버킷리스트 로직
├─ config.js           Firebase 설정 (직접 채우기)
├─ firestore.rules     Firebase 보안 규칙 (콘솔에 붙여넣기)
├─ encrypt_photos.py   사진 암호화 스크립트
├─ assets/             배경 그림 (art by @_umeus_)
├─ gallery/            🔐 암호화된 사진 → GitHub에 올라감
└─ photos_raw/         📷 원본 사진 → GitHub에 안 올라감 (.gitignore)
```

## 0. 비밀번호는 두 개야
- **4자리 (사이트 입장, 매번)**: `config.js`의 `SITE_PIN` 값을 바꾸면 돼. 화면 잠금용이라 소스에서 보이는 값이야.
- **문장 비밀번호 (사진·버킷리스트 열쇠)**: `encrypt_photos.py` 처음 실행 때 정해. 기기마다 처음 한 번만 입력해.

## 1. 문장 비밀번호 정하기 + 사진 넣기
```bash
pip install pillow cryptography        # 아이폰 HEIC면 pillow-heif 도
python3 encrypt_photos.py              # 처음 실행 때 비밀번호(8자 이상) 설정
```
사진 추가/삭제: `photos_raw/`에서 넣고 빼고 → 다시 실행 → `gallery/` push.

## 2. Firebase (버킷리스트 공유)
1. console.firebase.google.com → 프로젝트 만들기 (Analytics 꺼도 됨)
2. 빌드 → Firestore Database → 데이터베이스 만들기 (프로덕션 모드)
3. Firestore → 규칙 탭 → `firestore.rules` 내용 붙여넣고 게시
4. 프로젝트 설정 → 내 앱 → 웹(</>) 앱 추가 → 나오는 값을 `config.js`에 복사
5. (권장) Google Cloud 콘솔에서 apiKey 제한: HTTP 리퍼러를 `https://chanyoung-roh.github.io/*` 로

## 2-1. 폰에서 사진 올리기 (갤러리)
- 갤러리의 `📷 지금 찍기` / `🖼️ 앨범에서` → 필름 느낌 + 날짜 도장 → 암호화해서 Firestore `photos` 컬렉션에 저장
- `firestore.rules`가 바뀌었으면 **콘솔 → Firestore → 규칙**에 다시 붙여넣고 게시해야 올리기가 동작해
- 4장부터는 한 줄로 옆으로 넘기기 (아래 막대가 위치 표시), `전체 보기`를 누르면 바둑판으로 펼쳐져
- 사진 한 장 ≈ 200~300KB (무료 1GiB 기준 약 3,000장). 폰에서 올린 사진만 사진 화면의 `지우기`로 지울 수 있어

## 2-2. 이모티콘 (오른쪽 아래 하트)
- 누르면 상대방 화면에 바로 뜨고, 상대가 페이지를 안 열어 뒀으면 다음에 열 때 떠 (푸시 알림은 아직 X)
- 새 이모티콘: `assets/emoticon/`에 그림(정사각형 PNG 추천) 넣고 → `python3 update_emoticons.py` → `list.json`에서 이름표 고치기 → push
- 처음 쓰는 기기에서는 ⚙️ 설정(또는 하트 창)에서 🐻/🐰 "나는 누구?"를 한 번 골라야 보낼 수 있어

## 2-3. 우리들의 레시피 (맨 아래)
- 메뉴 이름 + 레시피 링크(선택) → 추가. 앱의 "공유 → 복사" 문구를 링크 칸에 붙여 넣으면 링크만 뽑고 메뉴 이름도 채워 줘
- 별 1~5개로 맛 표시, 같은 별을 한 번 더 누르면 "아직 안 먹어 봄"으로 돌아가
- 링크는 http/https 주소만 저장돼 (이상한 링크는 거절)
- 먹어 본 메뉴(별 1개 이상)엔 🐻/🐰 각자 한 줄 후기 (내 것만 수정 가능), 위쪽 버튼으로 최신순 / ★ 높은 순 / 안 먹어 본 것 (기기마다 기억)

## 2-4. 오른쪽 점 슬라이더 (섹션 바로 가기)
- 점 누르기 → 그 섹션으로 / 점 위를 위아래로 끌기 → 이름 보면서 빠르게 이동
- 새 섹션을 만들면 `<section class="scene" data-nav="이름">` 처럼 `data-nav`만 붙이면 점이 자동으로 생겨

## 2-5. 서로 더 알아가기 (오늘의 질문)
- 매일 질문 하나 (그날 처음 연 사람 기준으로 정해지고 둘이 같은 질문). 내가 답해야 상대 답이 보여
- 질문은 하루에 딱 하나 (`하나 더`는 없음). 상대가 먼저 답한 지난 질문은 "기다리는 질문"에 모임
- 질문 추가는 `questions.js` 각 분류 맨 아래에 한 줄 (⚠️ 기존 질문 순서 바꾸거나 중간 삭제 금지)

## 2-6. 🔔 푸시 알림 (Cloudflare Worker)
- 알림 서버 코드: `cloudflare/worker.js` → Cloudflare Worker에 붙여넣기 + KV를 `PUSH` 이름으로 연결
- Worker 주소를 `config.js`의 `PUSH_URL`에 넣으면 ⚙️ 설정 창에 `🔔 알림 켜기` 버튼이 생겨
- 아이폰은 홈 화면에 추가한 앱에서만 켤 수 있어 (기기마다 한 번씩)
- 알림 문구는 `worker.js`의 `TEMPLATES`에서 고쳐

## 2-6-1. 🐶 같이 키우기 (레시피 ↔ 알아가기 사이)
- 강아지를 데려와서 둘이 같이 키워 (고양이·햄스터는 준비 중). 그림은 직접 만든 SVG (`index.html`의 `.dog`)
- 🦴 간식 얻기: 사진 1장 +1 · 버킷리스트 달성 +3 · 레시피 먹어 보기(별점) +2 · 오늘의 질문 답(각자) +1
  - 따로 적립하지 않고 "지금 개수 − 데려온 날 개수"로 계산 → 두 번 세거나 체크/해제 반복으로 늘릴 수 없음
- 간식 1개 = 경험치 +10, 배부름 +25. 배부름은 1시간에 4씩 줄어 (하루쯤이면 배고파 😢). 90% 이상이면 "배불러"
- 레벨: 1~4 아기 · 5~9 꼬마 · 10~ 어른 (클수록 그림이 커져)
- 숫자 조절은 `app.js`의 `PET_EARN`, `PET_FEED_EXP`, `PET_DECAY` 등
- 저장: 암호화돼서 Firestore `couples/{sha256(docId + ':pet')}`
- 🎮 놀이 → 🪵 통나무 타기 (`games/logroll.js`): 앞으로 기울면 ◀ 뒤로, 뒤로 기울면 앞으로 ▶ (화면 왼쪽/오른쪽 터치, 키보드 ←/→도 OK)
  - 시간이 갈수록 넘어가려는 힘·바람·돌풍·속도가 세져. 점수는 간 거리(m)
  - 난이도 조절: `games/logroll.js` 위쪽 숫자와 `update()`의 G·A 식
- 🎮 놀이 → ⚾ 공 받기 (`games/ballcatch.js`): 상대(🐻/🐰)가 던진 공이 날아오면, 줄어드는 동그라미가 점선에 겹칠 때 🐾 잡아! (화면 터치, 스페이스바도 OK)
  - Perfect +3 / Good +1, 10콤보마다 x2 (최대 x3). 놓치면 ♥ 하나, ♥ 3개 다 잃으면 끝
  - 공이 많아질수록 빨라지고 자주 오고, 판정 구간도 좁아져. 높은 공·빠른 공·튀기는 공, 30개 넘으면 연달아 두 개
  - 잡는 곳(점선): 처음엔 가운데 위쪽 → 5개 잡으면 📍 공마다 새 자리 → 10개 잡으면 🌀 계속 움직여 (강아지가 밑으로 따라가고, 그 높이까지 점프). 숫자는 `games/ballcatch.js`의 `MOVE_AT`, `DRIFT_AT`
- 🎮 놀이 → 🏃 허들 넘기 (`games/hurdle.js`): 구글 공룡 게임처럼 계속 달려. 허들은 ⬆ 점프(길게 누르면 더 높이, 화면 터치·스페이스도 OK), 파란 새는 ⬇ 숙이기(누르는 동안, 공중에선 빨리 내려오기), 보라색 높은 새는 그냥 달리기(점프하면 부딪힘)
  - 한 번 부딪히면 끝. 약 1분 동안 점점 빨라지고 장애물도 촘촘해져. 허들 4개 넘으면 새, 180m부터 두 개 연속 허들, 260m부터 높은 새
- 🎮 놀이 → 🐻🐰 곰토 나누기 (`games/sort.js`): 가운데 줄로 토끼찡·곰돌찡이 계속 내려와. 맨 아래(동그라미) 친구가 토끼찡이면 ◀ 왼쪽, 곰돌찡이면 오른쪽 ▶ (배경 만화랑 같은 방향) (아래 버튼 / 화면 왼쪽·오른쪽 터치 / 키보드 ←·→)
  - 틀리거나 못 누르고 빨간 선을 넘으면 ♥ 하나, ♥ 3개 다 잃으면 끝. +1점, 10콤보부터 x2, 20콤보부터 x3
  - 맞힐수록 빨라져 (`intervalOf`: 한 칸 0.95초 → 최고 0.34초). 빨리 고르면 줄이 쭉 내려와서 기다릴 필요 없음
  - 이모티콘 종류는 시간에 따라: 0초 2종(여보세용 🐰·싱나 🐻) → 20초 4종(+히히·최고!) → 40초 6종(+뽀뽀할래?·사랑해). 종류마다 이모티콘 하나로 고정 (`STAGES`)
  - 😈 30초부터 함정 "시러"(`no_bear.png`)가 섞여 → **반대쪽(◀ 왼쪽)**으로! 처음 나올 땐 "◀ 반대로!" 표시 (`TRAP_AT`, `TRAP_P`)
  - 🔀 60초부터 3~5초마다 위쪽 친구들(최대 4명, 지금 차례·선에서 2칸 안쪽 제외)이 부르르 떨다가 순서가 바뀌어 (`SHUF_AT`, `SHUF_N`)
  - 등장 순서: `app.js`의 `SORT_ORDER` (바꾸고 싶으면 파일 이름만 바꾸기). 같은 친구는 최대 4번 연속(`MAX_RUN`). 배경 = `assets/comic.jpg`
- 게임 공통: 보상은 ⭐ 경험치만 (통나무 20m·공 25점·허들 80m·곰토 20점마다 +1, 한 판 최대 +10), 게임마다 각자 하루 3판. 최고 기록은 🐻/🐰 따로
  - 보상·게임 목록: `app.js`의 `GAMES`, `GAME_DAILY` / 새 게임은 `games/`에 클래스 만들고 `GAMES`에 한 줄

## 2-6-2. 🍇 포도 심기 (칭찬 + 부탁 → 송이 → 포도밭)
- 왼쪽 위 탭: **🍇 포도 만들기** (아래 내용 그대로) / **🌿 포도밭 가꾸기** (이 기기에서 마지막 탭 기억)
- 💜 칭찬하기 → 상대 송이에 보라 포도 한 알 (언제든, 제한 없음, 🔔 알림 감)
- 🌱 부탁하기 → 고쳐야 하는 사람 송이에 **초록 포도로 바로 달려서 자리를 차지해**. **알림 없이 조용히** 전해져. 입력칸은 "~할 때 ~해서 속상했어. ~해주면 좋겠어" (나 전달법)
  - 받은 사람: 💪 노력할게 / 🙋 고쳐봤어(확인 요청)
  - **익히는 건 부탁한 사람만** ✨ → 그 자리에서 ⭐ 보라 포도로 익어 (+ 🐶 간식 +3)
  - 부탁한 사람은 언제든 거두기(삭제) 가능. 진행 중인 부탁은 각자 3개까지
- 포도는 받은 사람 송이에 생긴 순서대로 15알씩. **15자리가 다 차고 전부 보라색이어야** 송이 완성 = 🎟️ 소원권 1장
  - 초록이 남아 있으면 그 송이는 완성 안 되고, 그 뒤 포도는 다음 송이에 대기 (초록이 익거나 거둬지면 완성)
- 숫자 조절: `app.js`의 `GRAPE_BUNCH`(15), `GRAPE_ASK_MAX`(3)
- 알림 문구(praise/ripe/wish)는 `cloudflare/worker.js`의 `TEMPLATES` → **Worker에 다시 붙여넣어 배포해야 알림이 가**
- 저장: 암호화돼서 Firestore `couples/{sha256(docId + ':grape')}`

### 🌿 포도밭 가꾸기
- 송이를 다 채우면 🎟️ 소원권은 그대로 받고, **그 송이를 밭에 심을 수도 있어** (송이 1개 = 포도나무 1그루)
  - 심을 수 있는 수 = 완성 송이 − 이미 심은 수 (두 번 심기·부풀리기 불가). 심는 건 송이 주인만, 밭은 둘이 같이 하나
  - `🌱 심기` = 앞자리부터 / 빈 자리(+)를 누르면 거기에 심기. 심을 송이가 있으면 탭에 빨간 점
  - 나무를 누르면 누구의 몇 번째 송이인지 + 칭찬·고친 부탁 수 + 심은 날
  - 밭은 5칸씩 줄, 마지막으로 심은 줄 아래에 늘 빈 줄 하나가 생겨
- 🐶 키우는 펫이 밭을 돌아다녀 (누르면 한마디, 배고프면 느릿느릿 + 시무룩). 밭이 화면에 보일 때만 움직여
- 나중에: 다 키운 펫을 "포도밭으로 보내기" → `pets` 배열에 넣으면 밭에서 같이 돌아다님 (그림은 지금 강아지 SVG 재사용)
- 크기·칸 조절: `app.js`의 `FCOLS`(한 줄 칸 수), `FARM_PET_W`(펫 크기)
- 저장: 암호화돼서 Firestore `couples/{sha256(docId + ':vineyard')}` = `{ vines: [{ id, owner, n, slot, at }], pets: [{ id, kind, name, exp, at, retiredAt }] }`

## 2-7. ⚙️ 설정 (오른쪽 위 톱니)
- **💞 우리 둘이 같이** (암호화돼서 Firestore `couples/{sha256(docId + ':settings')}`에 저장 → 상대 화면도 같이 바뀜)
  - 만난 날: 위쪽 "우리 만난 지 N일" + 달력의 100일·N주년 표시가 이걸 따라가 (값이 없으면 `app.js`의 `START_DATE` 기본값)
  - 만난 날을 1일로 세기: 끄면 만난 날이 0일
  - 🎂 생일 (🐻/🐰): 달력에 매년 "N번째 생일"로 자동 표시 + 일정 부제에 가까운 생일 D-day (2월 29일생은 평년엔 2월 28일). 양력만 돼
- **📱 이 기기** (localStorage): 나는 누구? 🐻/🐰 · 사진 올릴 때 기본값(필름/날짜 도장) · 🔔 알림 · 🔒 잠그기 · 이 기기 잊기
- "나는 누구?"를 아직 안 고른 기기는 톱니에 빨간 점이 떠
- 🧩 보일 메뉴 · 순서 (이 기기): 메뉴별 보이기/숨기기 + ▲▼로 순서 바꾸기. 첫 화면 그림은 맨 위 고정(숨기기만), 기능 메뉴는 최소 하나는 보여야 해
  - 숨긴 메뉴도 데이터는 계속 불러와 (키우기 간식 계산 등). 점 슬라이더·맨 아래 footer도 자동으로 따라가
  - 저장: localStorage `couple-layout`. 새 섹션은 `<section data-sec="키">`만 붙이면 기본 위치에 자동으로 들어가 (`SEC_INFO`에 이름 추가)
- 새 설정 추가: 둘이 같이 쓰는 건 `app.js`의 `normSet()`에, 기기 설정은 `prefs()`에 기본값을 넣고 `index.html`의 `#setSheet`에 칸 추가
